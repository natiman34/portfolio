## Featured Projects

### AMN — Student Attendance Management Application

An offline-first classroom attendance application for rosters of up to 120 students,
built with no backend dependency.

- **Problem:** paper attendance is slow, error-prone to tally and impractical without
  constant internet access.
- **Solution:** a structured roster and session-level attendance workflow that records
  Present/Absent locally and produces session summaries immediately.
- **Highlights:** supports large rosters, works offline, responsive on mobile and desktop.
- **Stack:** HTML5, CSS3, JavaScript, offline storage, Android workflow.

### PlanDroid — Productivity & Focus Application

A daily planning workspace that combines task planning, timed focus sessions, goal
tracking and daily progress summaries.

- **Problem:** switching between separate task lists, timers and goal trackers breaks
  concentration.
- **Solution:** one calm, responsive interface linking daily plans, focus blocks and goal
  completion into a single summary view.
- **Stack:** HTML5, CSS3, JavaScript, responsive UI, application logic.

### Final Year Full-Stack Web Application

A Computer Science capstone project delivered with a university team, combining
full-stack implementation with Agile sprint planning.

- **Role:** Project Manager & Developer.
- **Solution:** clear component boundaries, API contracts defined early, and collaborative
  Git workflows connecting React views with Node.js application logic.
- **Stack:** React, Node.js, JavaScript, CSS, Git, Agile workflow.

## Local Development

```sh
npm install
npm run dev       # http://localhost:3000
npm run build     # production bundle in dist/
npm run preview   # preview the production build
npm run lint
```

**Built with** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui and React Router.
Fonts are self-hosted variable files; all site content lives in
`src/data/portfolioData.ts`.
